# Модули проекта

Здесь описываются отдельные компоненты системы и их связь с приложением из `projects/src/`.

Планируемые логические компоненты:
- каталог сельскохозяйственной техники;
- поиск, фильтрация и сравнение;
- интеллектуальный подбор (RAG);
- управление данными поставщиков и аутентификация.

Это планируемое разбиение, а не описание уже реализованных программных модулей. Код не следует дублировать одновременно в `modules/` и `projects/src/`.

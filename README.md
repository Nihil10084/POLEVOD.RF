# Полевод.РФ

## Назначение
«Полевод.РФ» — веб-приложение для интеллектуального подбора сельскохозяйственной техники. Система помогает агрономам, представителям КФХ и агрохолдингов находить, изучать и сравнивать модели техники, а поставщикам — размещать сведения о своей продукции.

## Основные возможности
- Просмотр каталога, ручной поиск, фильтрация и сортировка.
- Детальная карточка техники с характеристиками и контактами дилеров.
- Интеллектуальный подбор с пояснением рекомендаций на основе RAG.
- Сравнение нескольких моделей.
- Регистрация поставщиков и добавление техники.

## Текущее состояние
Учебный проект на этапе подготовки требований, UML-диаграмм и структуры репозитория. Программная реализация ещё не размещена.

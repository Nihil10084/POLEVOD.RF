# Проверки и тесты

На текущем этапе программная реализация отсутствует, поэтому автоматические тесты не созданы. После реализации здесь будут размещаться тестовые случаи, автоматические тесты и инструкции по их запуску.

Для каждого тестового случая следует фиксировать предусловия, действия и ожидаемый результат. Выполненные проверки отмечаются отдельно от запланированных. Наличие этого каталога само по себе не означает, что тестирование или CI настроены.

# Исходники диаграмм

Поместите сюда редактируемые исходные файлы диаграмм (например, `.drawio`, `.puml` или файлы редактора, в котором они создавались).

В текущем комплекте есть PNG-изображения диаграмм в `docs/img/`, но исходные редактируемые файлы не предоставлены. Не переименовывайте PNG в `.drawio`: это не восстановит редактируемую структуру.
